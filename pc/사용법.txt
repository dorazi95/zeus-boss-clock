제우스 보스 시계 - PC 위젯
==========================

화면 위에 항상 떠 있는 작은 시계입니다.
모든 보스가 고정 시간 젠이라 컷 입력이 없고, 정해진 시각으로 계속 돕니다.

  웹 주소: https://dorazi95.github.io/zeus-boss-clock/

설치
----
1. 압축을 아무 폴더에나 풉니다. (바탕화면도 상관없음)
2. boss-clock.ps1 우클릭 > 속성 > 아래쪽 [차단 해제] 체크 > 확인
   (인터넷에서 받은 파일이라 처음 한 번만 필요합니다)
3. "위젯 링크 등록.cmd" 를 한 번 실행합니다.
   이걸 해두면 웹 페이지의 [PC 위젯 열기] 버튼으로 바로 켤 수 있습니다.
4. 실행은 "보스시계 실행.cmd" 더블클릭, 또는 웹의 [PC 위젯 열기] 버튼.

윈도우 기본 PowerShell로 동작하므로 따로 설치할 건 없습니다.

화면 구성
---------
[ 다음다음 보스 | 그 다음 보스 ]   <- 미리보기 2칸 (이름과 남은시간)
[ 다음 보스 이름              ]
[ 0:00:00                ◐ ]   <- 가장 가까운 보스까지 남은 시간

- 남은 시간이 3분 이하가 되면 위젯 전체가 빨간색으로 바뀝니다.
- 젠 시각이 지나면 자동으로 다음 회차로 넘어갑니다. 인터넷 연결도 필요 없습니다.

조작
----
- ◐ 버튼 : 다크 모드 / 일반 모드 전환
- 드래그  : 아무데나 잡고 끌면 이동 (위치는 자동 저장, 화면 밖으로는 안 나감)
- 우클릭  : 모드 전환 / 3분 전 소리 알림 켜기끄기 / 웹에서 보기 / 위치 초기화 / 종료

3분 전 소리 알림
----------------
보스 출현 3분 전에 알림음과 함께 "보스명 3분 전입니다" 라고 읽어줍니다.
기본으로 켜져 있고, 우클릭 메뉴에서 끌 수 있습니다.
웹과 달리 위젯은 클릭 없이도 소리가 나기 때문에 게임 중에도 들립니다.

젠 시각이 바뀌면
----------------
게임 패치로 젠 시각이 바뀌면 boss-clock.ps1 위쪽의 보스 목록에서
Times=@('00:29','08:29','16:29') 부분만 고치면 됩니다.

파일
----
boss-clock.ps1      : 본체
widget.json         : 위젯 위치 / 테마
보스시계 실행.cmd   : 실행용
위젯 링크 등록.cmd  : 웹의 [PC 위젯 열기] 버튼과 연결
