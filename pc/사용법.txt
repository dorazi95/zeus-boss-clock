제우스 보스 시계 - 사용법
=========================

설치
----
1. 압축을 아무 폴더에나 풉니다.
2. boss-clock.ps1 우클릭 > 속성 > 아래쪽 [차단 해제] 체크 > 확인
   (인터넷으로 받은 파일이라 처음 한 번만 필요합니다)
3. "보스시계 실행.cmd" 더블클릭

윈도우 기본 PowerShell로 동작하므로 따로 설치할 건 없습니다.

기본 시간표는 2026-09-16 11:12 기준으로 넣어둔 값입니다.
서버가 다르거나 시간이 어긋나면 설정 창에서 다시 넣으면 됩니다.

화면 구성
---------
[ 다음다음 보스 | 그 다음 보스 ]   <- 미리보기 2칸 (윗줄 이름, 아랫줄 남은시간)
[ 가장 가까운 보스 이름   [ON] ]   <- 온라인 모드 토글
[ 0:00:00              [컷]  * ]

- 아래 큰 칸: 체크한 보스 중 가장 가까운 1마리.
  출현 시각이 지나면 "보스이름 . 출현 중"으로 바뀌고
  큰 숫자는 출현 후 경과 시간(+12:34)이 되며 [컷] 버튼이 나타난다.
- 위 2칸: 큰 칸 다음으로 가까운 보스 2마리를 미리 보여준다.
  이미 출현한 보스가 여러 마리면 그쪽이 먼저 나온다.

남은 시간 5분 경고
------------------
큰 칸의 남은 시간이 5분 이하로 떨어지면 위젯 전체가 빨갛게 바뀐다.
출현하거나 다른 보스로 넘어가면 원래 색으로 돌아온다.

온라인 모드 (ON / OFF)
----------------------
이름 줄 오른쪽의 [ON] / [OFF] 버튼으로 켜고 끈다.
우클릭 > 온라인 모드 로도 된다. 설정은 저장되어 다음 실행에도 유지된다.

  ON  : 내가 직접 치는 중. 출현 시각이 지나면 컷을 누를 때까지
        계속 "출현 중"으로 남는다. 자동으로 다음 젠으로 넘어가지 않는다.
        여러 마리가 밀려 있으면 미리보기 칸에도 "출현 중"으로 쌓인다.
  OFF : 방치 중. 출현 후 아래 "컷분"이 지나면 알아서 다음 젠으로 넘어간다.

ON일 때는 컷을 안 누르면 계속 밀려 있으니, 안 잡고 넘길 보스는
설정 창에서 체크를 해제해 두는 편이 낫다.

컷 버튼과 자동 진행
-------------------
OFF일 때는 컷을 안 눌러도 알아서 다음 주기로 넘어간다.
계산식은 "출현 + 잡는시간(컷분) + 주기" 이고, 컷분은 보스마다 정해져 있다.

  Lv35 1분 / Lv40 2분 / Lv45 3분 / Lv65 15분 / Lv70 20분
  고트시스 10분 / 베딕스 8분 / 알라스토르 8분
  (추정값이라 실제와 다르면 설정 창에서 고치면 된다)

출현 직후 그 "컷분" 동안은 큰 칸에 "보스이름 . 출현 중"으로 뜨고
[컷] 버튼이 나타난다. 이때 누르면 실제 컷 시각 기준으로 다시 세므로
예상 시간과 어긋난 경우를 바로잡을 수 있다.

조작
----
- [컷] 버튼: 처치 시각 기록
- [ON]/[OFF] 버튼(이름 줄 오른쪽): 온라인 모드 토글
- 톱니바퀴 버튼(오른쪽 아래): 설정 창
- 드래그: 아무데나 잡고 끌면 이동 (위치 자동 저장, 화면 밖으로는 못 나감)
- 우클릭: 시간 설정 / 온라인 모드 / 위치 초기화 / 종료

설정 창 (톱니바퀴 또는 우클릭 > 시간 설정)
------------------------------------------
- 체크박스: 체크한 보스만 카운트다운에 나온다.
  모두 선택 / 모두 해제 버튼으로 한번에 바꿀 수 있다.
- 남은시간: 시:분:초 형식이다. 48분은 "0:48:00"으로 적는다.
  게임 [콘텐츠 현황판] 표기도 그대로 인식한다.
  "6시간 51분", "29분 44초", "51분", "1:39:20" 모두 된다.
  저장한 시각 기준으로 다음 출현 시각이 계산된다.
  주의: "48:00"처럼 두 칸으로 적으면 48시간으로 읽는다. 분을 넣을 때는
  "48분" 또는 "0:48:00"으로 적을 것.
- 남은시간이 젠 주기보다 길면 저장할 때 한 번 물어본다.
- 주기h: 컷 이후 리젠까지 걸리는 시간. 컷분: 출현 후 잡는 데 걸리는 시간.
  기본값은 아래와 같다.

  크리소파고스 / 아모르포스 / 트라손        8시간
  알라스토르 / 베딕스 / 고트시스            8시간
  봉인된 아모르포스                         8시간
  이오칸토스 / 키니 러우리 / 트리포크       12시간
  거인의 세번째 손                          12시간 (기본 체크 해제)
  봉인된 브델레스                           24시간

주간 보스 5종은 입력할 필요 없이 자동 계산된다. 모두 21시 출현.

  월요일  아르고스     (자하브)
  화요일  메데이아     (타르타로스 2계)
  수요일  아라크네     (테살리아)
  금요일  케르베로스   (타르타로스 5계)
  토요일  키메라       (타르타로스 4계)

파일
----
boss-clock.ps1      : 본체
bosses.json         : 보스 목록 / 체크 여부 / 주기 / 다음 출현 시각 / 위젯 위치
보스시계 실행.cmd   : 실행용
