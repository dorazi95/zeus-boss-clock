제우스 보스 시계 - PC 위젯
==========================

화면 위에 항상 떠 있는 작은 시계입니다.
공유 서버의 시간을 받아 보여주기만 하고, 컷 입력과 설정은 웹에서 합니다.

  웹 주소: https://dorazi95.github.io/zeus-boss-clock/

설치
----
1. 압축을 아무 폴더에나 풉니다. (바탕화면도 상관없음)
2. boss-clock.ps1 우클릭 > 속성 > 아래쪽 [차단 해제] 체크 > 확인
   (인터넷에서 받은 파일이라 처음 한 번만 필요합니다)
3. "위젯 링크 등록.cmd" 를 한 번 실행합니다.
   이걸 해두면 웹 페이지의 [PC 위젯 열기] 버튼으로 바로 켤 수 있습니다.
4. 실행은 "보스시계 실행.cmd" 더블클릭, 또는 웹의 [PC 위젯 열기] 버튼.

윈도우 기본 PowerShell로 동작하므로 따로 설치할 건 없습니다.

화면 구성
---------
[ 다음다음 보스 | 그 다음 보스 ]   <- 미리보기 2칸 (이름과 남은시간)
[ 다음 보스 이름              ]
[ 0:00:00                ◐ ]   <- 가장 가까운 보스까지 남은 시간

- 남은 시간이 5분 이하가 되면 위젯 전체가 빨간색으로 바뀝니다.
- 젠 시각이 지난 보스는 "출현 중"으로 표시되고, 누군가 웹에서 컷을 누르면
  15초 안에 이 위젯도 같이 바뀝니다.
- 서버에 연결되지 않으면 이름 옆에 (오프라인)이 붙고 마지막으로 받은
  시간으로 계속 돕니다. 연결되면 자동으로 최신 값을 받아옵니다.

조작
----
- ◐ 버튼 : 다크 모드 / 일반 모드 전환
- 드래그  : 아무데나 잡고 끌면 이동 (위치는 자동 저장, 화면 밖으로는 안 나감)
- 우클릭  : 모드 전환 / 웹에서 컷 입력하기 / 위치 초기화 / 종료

컷은 어디서 누르나요
--------------------
웹 페이지에서 누릅니다. 위젯 우클릭 > "웹에서 컷 입력하기" 를 고르면 열립니다.
웹에서 누른 컷은 이 위젯을 포함해 모두의 화면에 반영됩니다.
시간이 실제와 어긋나면 웹에서 연필 버튼으로 현황판 값을 그대로 넣으면 됩니다.

파일
----
boss-clock.ps1      : 본체
widget.json         : 위젯 위치 / 테마 / 마지막으로 받은 시간
보스시계 실행.cmd   : 실행용
위젯 링크 등록.cmd  : 웹의 [PC 위젯 열기] 버튼과 연결
