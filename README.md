# 제우스 보스 시계

제우스: 오만의 신 보스 타이머. 웹 버전과 PC 위젯 두 가지.

## 웹 버전 (폰 / 두 번째 모니터)

https://dorazi95.github.io/zeus-boss-clock/

설치 없이 브라우저로 열면 됩니다. 폰에서는 크롬 메뉴 > 홈 화면에 추가.

- 가까운 순으로 보스 카운트다운, 체크한 보스만 표시
- 잡은 직후 **컷** 버튼을 누르면 그 시각부터 다음 젠을 다시 셉니다
- **온라인 모드 ON**: 컷을 눌러야 다음 젠으로 넘어감 / **OFF**: 잡는 시간이 지나면 자동
- 창 크기에 따라 화면이 바뀝니다
  - 작게 줄이면 다음 보스 하나만
  - 좁고 길게 늘이면 가까운 6종을 한 줄씩
  - 넓히면 전체 보드
- 창을 줄이면 맨 위에 다음 보스가 크게 나오고, **작은 창** 버튼을 누르면 항상 위에 뜨는 작은 창으로 띄울 수 있습니다
- 출현 5분 전 소리 알림 (페이지를 한 번 클릭해야 브라우저 소리 제한이 풀립니다)
- 다크 모드 / 일반 모드 전환
- 기록은 각자 브라우저에 저장됩니다
