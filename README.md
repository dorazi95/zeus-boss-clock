# 제우스 보스 시계

제우스: 오만의 신 보스 타이머. 모든 보스가 고정 시간 젠이라 컷을 칠 필요가 없고, 젠 시각을 맞추면 길드원 모두에게 바로 반영됩니다.

## 웹 버전

https://dorazi95.github.io/zeus-boss-clock/

설치 없이 브라우저로 열면 됩니다. 폰에서는 크롬 메뉴 > 홈 화면에 추가.

- 가까운 순으로 보스 카운트다운, 체크한 보스만 표시
- **고정 시간 젠** — 젠 시각이 지나면 자동으로 다음 회차로 넘어갑니다
- 창 크기에 따라 화면이 바뀝니다
  - 작게 줄이면 다음 보스 하나만
  - 좁고 길게 늘이면 가까운 6종을 한 줄씩
  - 넓히면 전체 보드
- 창을 줄이면 맨 위에 다음 보스가 크게 나오고, **작은 창** 버튼을 누르면 항상 위에 뜨는 작은 창으로 띄울 수 있습니다
- 젠 시각을 바꾸는 **✎ · 캡쳐 버튼은 관리자만** 보입니다 (아래 참고). 길드원에게는 보기 전용입니다
- **젠 시각은 링크를 쓰는 모두가 같이 봅니다.** 관리자가 맞추면 몇 초 안에 전원 화면에 반영됩니다
- 출현 3분 전 소리 알림 (페이지를 한 번 클릭해야 브라우저 소리 제한이 풀립니다)
- 다크 모드 / 일반 모드 전환
- 체크박스·테마·소리 설정은 각자 브라우저에만 저장됩니다

## 젠 시각 고치기 (관리자)

젠 시각을 바꾸는 버튼은 기본으로 숨어 있습니다. 내 브라우저에서 한 번만 아래 주소로 열면 켜지고, 그 뒤로는 그냥 링크로 들어가도 계속 보입니다.

    https://dorazi95.github.io/zeus-boss-clock/?edit=<코드>

또는 페이지 위쪽 **공유 중** 칸을 눌러 코드를 넣어도 됩니다. 끄려면 코드를 비우고 저장합니다. 브라우저마다 따로 켜야 합니다.

서버(Firebase) 규칙에도 같은 코드가 걸려 있어, 코드 없이는 쓰기 자체가 거부됩니다. 다만 짧은 숫자 코드라 작정하고 맞히려 들면 뚫립니다. 길드원이 임의로 바꾸는 것을 막는 수준입니다.
