# 제우스 보스 시계

제우스: 오만의 신 보스 타이머. 웹 버전과 PC 위젯 두 가지.

## 웹 버전 (폰 / 두 번째 모니터)

https://dorazi95.github.io/zeus-boss-clock/

설치 없이 브라우저로 열면 됩니다. 폰에서는 크롬 메뉴 > 홈 화면에 추가.

- 가까운 순으로 보스 카운트다운, 체크한 보스만 표시
- 잡은 직후 **컷** 버튼을 누르면 그 시각부터 다음 젠을 다시 셉니다
- **온라인 모드 ON**: 컷을 눌러야 다음 젠으로 넘어감 / **OFF**: 잡는 시간이 지나면 자동
- 창 크기에 따라 화면이 바뀝니다
  - 작게 줄이면 다음 보스 하나만
  - 좁고 길게 늘이면 가까운 6종을 한 줄씩
  - 넓히면 전체 보드
- 밝은 모드 / 어두운 모드 전환
- 기록은 각자 브라우저에 저장됩니다

## PC 위젯 (항상 위에 뜨는 작은 창)

[boss-clock.zip 받기](../../raw/main/boss-clock.zip)

공유 서버의 시간을 받아 **보여주기만** 합니다. 컷 입력과 설정은 웹에서 하세요.

1. 압축을 아무 폴더에나 풉니다
2. `boss-clock.ps1` 우클릭 > 속성 > 아래쪽 **차단 해제** 체크 (처음 한 번만)
3. `위젯 링크 등록.cmd` 한 번 실행 — 웹의 **PC 위젯 열기** 버튼과 연결됩니다
4. 실행은 웹의 [PC 위젯 열기] 버튼 또는 `보스시계 실행.cmd`

- 다음 보스 큰 카운트다운 + 그 다음 2마리 미리보기
- 5분 이하가 되면 위젯 전체가 빨간색
- ◐ 버튼으로 다크 모드 / 일반 모드 전환
- 누가 웹에서 컷을 누르면 15초 안에 위젯도 같이 바뀝니다
